🤖 KubeAgent: Autonomous Site Reliability Engineer

LangGraph Kubernetes Llama-3 Python

A multi-agent orchestrated system that autonomously diagnoses and remediates Kubernetes cluster failures with Human-in-the-Loop safety gates.

📺 Live Demo

System Architecture

  • Investigator Node: Diagnoses errors via read-only K8s events and logs.
  • Planner Node: Uses Pydantic to draft strict JSON remediation plans.
  • Gatekeeper: Pauses for human approval before mutating production.
  • Executor: Applies patches (Scaling, Restarting, Image Updates) to the K8s API.
